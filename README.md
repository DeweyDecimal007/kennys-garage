# Kenny's Garage

**Idle mechanic, car building & racing game**

Build skills at vocational school, work jobs at NPC shops, scavenge the junkyard, buy and tune classic American muscle cars (Chevy, Ford, Dodge), race them, and grow from your parents' garage into a professional shop.

## Idle Time System

- **24 real minutes = 1 full game day**
- **1 real minute = 1 game hour**
- Time continues advancing even when the browser tab is closed or the computer is asleep.
- On return, the game catches up (capped at 2 game days of offline progress for balance).
- School courses take real time (e.g. a 2-day course = 48 real minutes).
- Optional passive income from garage level and a chosen job.

## How to Play

1. Open `index.html` in any modern browser (or visit the GitHub Pages link if enabled).
2. Work the minimum-wage job or hit the Junk Yard to start earning.
3. Enroll in Basic Mechanics when you can afford it.
4. Buy a project car, install parts, repair, and enter races.
5. Upgrade your garage as reputation grows.

Progress is saved automatically in your browser (localStorage).

## Features

- Full skill system + OJT
- Multiple NPC workplaces (Jerry’s Junk Yard, Pete’s Parts, Al’s Auto Repair, etc.)
- Random-quality junkyard parts + three tiered shops
- Weight / HP / handling physics for every part
- Drag, dirt, short track, road course, and endurance racing
- Damage system on cars and parts
- Garage progression path exactly as designed
- Mobile-friendly dark UI with custom graphics

## Tech

Pure HTML + CSS + vanilla JavaScript. Single self-contained file with embedded images. No build step, no frameworks.
