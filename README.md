# Kenny's Garage

Idle mechanic, car building, and racing game.

Build skills at vocational school, work jobs, scavenge the junkyard, buy and tune classic American muscle cars (Chevy, Ford, Dodge), race them, and grow from your parents' garage into a professional shop.

## Play

1. Open `index.html` in any modern browser (Safari, Chrome, etc.).
2. Keep `logo.jpg`, `kenny.jpg`, and `cars.jpg` in the same folder for graphics (optional — the game still plays without them).
3. Progress is saved automatically in your browser (`localStorage`).

## Idle time

- **24 real minutes = 1 game day**
- **1 real minute = 1 game hour**
- Time keeps running when the tab is closed.
- Offline catch-up is capped at 2 game days.
- The day timer resets each game day (countdown + progress bar).

## Day / night schedule

- **Day School**: normal length. Blocks daytime jobs. Evenings free for helping friends or working on your own cars.
- **Night School**: takes twice as long. Allows a daytime job. Blocks evenings.
- One daytime job per game day.
- One evening slot per game day (help a friend **or** install/repair your own car).
- No night jobs yet.

## Other features

- Character name, new character (keeps medals and high scores)
- Medals / trophies and high scores
- Skills + OJT
- Random-quality junkyard parts and three shop tiers
- Weight / HP / handling on parts
- Drag, dirt, short track, road, and endurance racing
- Garage path: Parents' → School → Friend's → Home 1/2-car → Professional
